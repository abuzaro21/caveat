# Thesis: memory should say how it knows

An agent that remembers is making a claim every time it recalls something. Today most agent memory treats recall as retrieval. It finds the closest text and uses it, and the agent sounds equally sure whether the memory came from you yesterday, from a courier's log, or from its own guess last week. That is why memory feels magical in demos and unsettling in use: people cannot tell when it is wrong, and they cannot make it truly forget.

CAVEAT treats memory as evidence. Each memory carries:

- where it came from;
- whether that source is entitled to establish this kind of fact;
- when it was last confirmed, measured against how fast this kind of fact changes;
- where and to whom it applies.

The agent's confidence is not a feeling or a percentage. It is a verdict computed from those properties, and it decides what the agent may *do*. A contested or stale memory can inform an answer with a caveat, but it cannot book a delivery. "I might be wrong about this" then becomes a precise statement with a reason attached, rather than a disclaimer.

Forgetting is the other half. A memory system earns trust when deletion is verifiable: the content is gone from every store the system controls, the topic cannot be relearned from old copies, and the receipt is honest about what lies beyond its reach.

**Prediction for 2028:** by the end of 2028, at least one major consumer AI assistant will show users the source and last-confirmed date of a remembered personal fact at the moment it acts on it, and will let them delete that memory with a verifiable receipt. Provenance at recall time will be a selling point, the way end-to-end encryption became one for messaging.

Agents will be judged less by how much they remember than by how well they know the limits of what they remember.
