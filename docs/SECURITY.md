# Security

CAVEAT is a public demo with no accounts and no real personal data. The threat model is about **memory integrity and deletion**: who can make the agent believe something, act on something, or keep something it was told to forget.

## Threat model

| Threat | Control | Test |
|---|---|---|
| One visitor reads or changes another's memory | Every row is keyed by session. Every query and mutation runs under that session's lock. The session id is sha256 of an HttpOnly, SameSite=Strict cookie token. | `adversarial.test.ts` (cross-session), e2e isolation |
| Sam reads Maya's sensitive memory | Access rules: only the subject may inspect, and consent purposes are enforced | `policy.test.ts` |
| A caller forges authority, for example an import claiming to be Maya's own statement | The source kind comes from the channel, never the payload. Unsigned imports are third-party reports with one fixed lineage and earn no corroboration credit. | `adversarial.test.ts`, `review1.test.ts` R1-2, R1-3 |
| Prompt injection inside imported text | Text is data. Nothing interprets it: there is no LLM, and the policy reads only typed fields. | `adversarial.test.ts` |
| A tampered or foreign signed export | HMAC-SHA256 over the body with a server secret, bound to the session. A mismatch downgrades it to unsigned. | `adversarial.test.ts` |
| A forgotten memory is resurrected (old export, re-dated copy, delayed worker, race, restart) | Content-free tombstones checked at ingest, a revision fence, a cache floor and locked transactions | [FAILURE-TEST.md](FAILURE-TEST.md) |
| A consequential action rests on uncertain memory | The backend recomputes the plan inside the booking transaction and returns 409 unless every needed memory is USE | `http.test.ts`, `scenarios.test.ts` |
| Cross-site requests | POST requires `application/json` (no form-encoded CSRF). SameSite=Strict cookie. CSP `form-action 'none'`, `frame-ancestors 'none'`. | `http.test.ts` |
| Path traversal on static files | Decode in try, resolve, then a `path.relative` containment check. Rejects `..`, absolute paths and NUL. | `review1.test.ts` R1-7 |
| Malformed requests crash the server | URL parsing inside the error boundary returns 400 | `review1.test.ts` R1-1 |
| Resource exhaustion | 300 requests per minute per client; 10 new sessions per minute per address; 1,500 sessions in total, with idle expiry after 3 h. Request bodies up to 64 KiB; 200 evidence rows per session; 50 items per import; excerpts truncated to 280 characters with control characters stripped; virtual clock bounded to 3 years. | `http.test.ts`, `adversarial.test.ts` |
| Memory content in logs | Logs record method, path and error class only | `http.test.ts` scans logs across forget, import and errors |
| Spoofed client IP behind the proxy | `X-Forwarded-For` is trusted only to the configured hop count (`CAVEAT_TRUST_PROXY_HOPS`) | `http.test.ts` |

**Response headers:**
- CSP `default-src 'self'`, with no inline script or style and `base-uri 'none'`.
- `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`, `X-Frame-Options: DENY`.
- A restrictive `Permissions-Policy` and `Cross-Origin-Opener-Policy: same-origin`.
- HSTS when served over TLS.

## Secrets

`CAVEAT_SECRET` (at least 16 characters) signs exports. On Render it is generated by the platform (`generateValue`), and it never appears in the repository or logs. The CI and e2e configurations use clearly labelled test-only values.

## Known limits

- PostgreSQL storage below the query layer, and provider backups, are not byte-scrubbed. See [PRIVACY-AND-FORGETTING.md](PRIVACY-AND-FORGETTING.md).
- Rate limits are in-process, so they reset on restart and are per instance.
- No authentication beyond the anonymous session, by design: there is nothing to protect except a fictional household.
